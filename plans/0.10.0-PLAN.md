# 0.10.0-PLAN.md — implement the graph-native spec family

Status: working plan (files only — the graph cannot represent this yet; it is the substrate we
are building). Version target: **0.10.0**, completed **prior to the 1.0.0 (Cosanima) release**,
which has its own spec.

## Objective

Implement the graph-native active-knowledge model and its spec lifecycle into the apg CLI by
0.10.0: the **4-tier graph** (Requirements / Domain / Solution / Implementation), the
**graph-wide invariant mechanism**, **branch-as-change-set versioning** (a project = a git
branch; apply = merge into main), and the **spec → plan → execute → apply** flow — replacing
the `future/` namespace and archive machinery, and retiring the `apg plan retag` band-aid.

## Reference specs

- **Invariants-SPEC.md** — graph-wide invariant mechanism (`Invariant` node, `GuardedBy`/
  `Checks`, emergent lifecycle).
- **GraphModel-SPEC.md** — the 4-tier active-knowledge graph: node taxonomy, spine edges,
  branch-as-change-set versioning, no `future/` namespace, no archive, squash/rebase
  dependency model, per-tier role ownership.
- **SpecCreation-SPEC.md** — capture + writing flow (spec-writer authors tiers 1–3; the
  reviewer loop; invariants).
- **PlanCreation-SPEC.md** — plan creation (plan-writer plans the tier-4 delta; breakdown →
  structural holistic review → parallel per-phase writing/review → final holistic review).
- **PlanExecution-SPEC.md** — execution (assertion-only `plan done`, milestone-only
  `plan complete`, branch scans, divergence discovery + spec reconciliation, human gate).
- **PlanCompletion-SPEC.md** — apply-the-diff (coherence gate → agent-operated merge → rebuild
  main; change-set consumed; nothing archived).

## Strategy

Oldschool, additive-first, each phase independently mergeable and gated green (`cargo test`):

1. **Extend the graph model + invariants** (low risk, additive) before changing the execution
   model.
2. **Change the execution/apply model** (plan lifecycle + branch versioning).
3. **Migrate the namespace + drop dead machinery** (touches everything — done late, once).
4. **Orchestrate the agent flows + dogfood** end to end.

See **PHASE_01.md … PHASE_05.md** for the detailed phase work items, deliverables, and done
gates.

## Out of scope (1.0.0 / later)

- The 1.0.0 Cosanima release itself (its own spec) — rename/org, MCP server, cross-harness
  agents.
- Database + infrastructure nodes (`Table`/`Column`/`Infrastructure`) in the Implementation
  tier.
- Removing the direct `Implements` shortcut beyond what the spine requires (the spine
  augments it; `Implements` stays as the terminal link).
