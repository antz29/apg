# OO sample fixtures

Hand-written COBOL 2002/2014 OO samples (fixed format, one construct focus per
file) and COBOL-85 keyword-regression probes. Facts are the SPEC §10 mapping.
Dialect: OO files run under `cobol2002` (and `cobol2014`); keyword probes run
under `cobol85`, then `cobol2002`, expecting identical facts (SPEC §8).

## NOTE lines (for the coordinator)

- NOTE: SPEC gives no rule for `INVOKE` whose receiver has no declared class (`any-obj`) or whose class is outside the scan (`JavaList`, `Widget`). §10 says external `unresolved_call`; untyped receiver category is open (`unknown` assumed).
- NOTE: the Micro Focus `PROPERTY` clause order (`AS "Name"` vs `WITH NO SET`) is written `PROPERTY AS "x" WITH NO SET`; the SPEC does not fix the order.
- NOTE: `INTERFACE-ID … INHERITS FROM` and `IMPLEMENTS` follow SPEC §10 wording; the standard clause positions are from the vendor manuals, not confirmed by a compiler (SPEC §17).
